# Airline Flight Operations Analytics Dashboard

This dashboard was developed using Databricks SQL to analyze airline flight performance and operational delays.

## Key Performance Indicators

- Total Flights: 1.32K
- Weighted On-Time Percentage: 68.28%
- Weighted Average Delay: 25.1 minutes
- Airlines (including Unknown): 6

## Visualizations

1. Total Flights by Airline
2. Average Delay by Airline
3. On-Time Percentage by Airline
4. Airline Performance Details
